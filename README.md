# Mojo Launcher



**Mojo Launcher** (also known as **MJLauncher**) is a free and open-source launcher that lets Android users play **Minecraft: Java Edition** on phones and tablets. Based on the PojavLauncher project, it brings the Java edition of Minecraft to Android mobile devices, supporting almost all other versions including snapshots and Combat Test versions.

## What Is Mojo Launcher?



Mojo Launcher is an Android-based Minecraft Java launcher. It is an app that allows Android players to play the Java version of Minecraft with various versions, mods, and customizable settings on their mobile phones. You don't need a computer to play this version. When you run the Java edition, you can only use Java features, such as hardcore mode, advanced redstone, and Java servers. You cannot access features of the Bedrock version or cross-play these games.



Note: MJLauncher is an Android-based Minecraft Java launcher. It is not a separate version of the Minecraft game. To play the game, you still need to have an appropriate Minecraft account and game access to use the Java Edition.

## Supported Minecraft Versions



Mojo Launcher supports **Minecraft versions from rd-132211 to 26.x**, so it can run almost all available Minecraft versions, from the very early releases to 26.x snapshots. It also supports snapshots and Combat Test versions, and the latest updates add support for Minecraft 26.2+.



## Mod Support



MJLauncher makes it possible to mod the Java edition of Minecraft on Android. It supports the **Forge** and **Fabric** mod loaders, as well as `.jar` mods and **OptiFine**. For modpacks, it supports **MRPACK** files and **CurseForge ZIP** modpacks, including local modpacks that can be imported directly.



To install Forge and Fabric mods, you should install the compatible Forge or Fabric loader for your Minecraft version, and then add the required mod files to that game. Lastly, open the launcher and play games.



## Rendering and Graphics



Mojo Launcher supports modern rendering options, including **GL4ES**, **ANGLE**, Freedreno, newer Mesa components, and Vulkan-related options. Adreno GPUs can take advantage of the **Turnip driver**, while Mali GPUs are supported through the **Zink plugin**. These options help match the renderer to your device's hardware.



## Controls



The customizable on-screen control feature helps players play Minecraft Java Edition on Android touchscreens smoothly. You can change the control layout for movement and other in-game actions, making the game easy to play without a physical keyboard and mouse. You can also configure controls for your touchscreen or connected peripherals when setting up the game.

## Mojo Launcher vs PojavLauncher



Mojo Launcher is based on PojavLauncher, so the two share a common foundation. Both are Minecraft Java launchers, both support Forge, Fabric, and OptiFine, and both are open source. PojavLauncher is the original project and supports Android and iOS, while Mojo Launcher targets Android and adds support for MRPACK and CurseForge ZIP modpacks along with GL4ES, ANGLE, and Vulkan-related rendering options. Mojo Launcher's current name is MJLauncher.



## FAQ



**Is it safe to use the MojoLauncher APK?**

Yes. When you download the MJLauncher from the official project source, it will be safe. However, if you install the APK version, you should also ensure you get it from a safe site.



**How can we install Forge and Fabric mods?**

You should install the compatible Forge or Fabric loader for your Minecraft version, and then add the required mod files to that game. Lastly, open the launcher and play games.



**Can we install MJLauncher on PC or Mac?**

No, MJLauncher is designed specifically for Android devices. So, you cannot install it as a native PC or Mac launcher.



**Is MojoLauncher removed permanently from the Google Play Store?**

No, the app is not permanently removed from the Google Play Store. It is mainly renamed as MJLauncher, and it has a Google Play listing under that name.



**Does the MJLauncher app support offline gameplay?**

No, it does not support offline gameplay. You must have a stable connection to use it and play games.
